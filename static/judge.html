A reproducible evaluation of AI-assisted event budgeting, exact-cent cost splitting, explicit human approval, and verified PayPal sandbox captures. No real funds are involved.

Two intentionally separate experiences. The public homepage uses fictional data in your browser and simulated contributions only. The protected integration workspace calls real Gemini and PayPal sandbox APIs; access credentials are provided privately in Devpost testing instructions. This avoids exposing AI usage and payment APIs to anonymous visitors.
Open to everyone

1 · Explore the public experience

  1. Open the public CircleSplit demo and select Event planner.
  2. Choose Friday Community Volleyball: $220 for 20 friends.
  3. Verify equal splitting yields $11.00 each and weighted splitting adjusts allocations without losing cents.
  4. Create a $10 event with three fictional participants and confirm shares add up to exactly $10.
  5. Open Contributions, approve a share and select Simulate; it must be labelled SIMULATED and must not charge anyone.

Reset demo restores local fictional data. This experience never contacts Gemini or PayPal.

Separate judge login

2 · Run the AI copilot

  1. Sign into the protected workspace with judge credentials supplied privately in Devpost.
  2. Open AI assistant and paste the sample note.
  3. Click Analyze expenses. A real Gemini response should extract $180, $25 and $30, totalling $235, and provide a rationale.
  4. Verify that every proposal remains editable and does not change an event until it is explicitly approved.
Our court costs $180, equipment $25 and refreshments $30. Twenty friends will attend.
PayPal sandbox only

3 · Verify one captured payment

  1. Create a new fictional $11 event with one participant in the protected workspace.
  2. Approve the participant's assigned share, then select PayPal test.
  3. Use a PayPal sandbox PERSONAL buyer account from the developer dashboard. Confirm checkout uses the sandbox PayPal hostname; never use real cards or live credentials.
  4. Approve checkout and return to CircleSplit. Activity should display VERIFIED CAPTURE, not just ORDER CREATED.
  5. If interrupted, use Activity → Check PayPal to resume the existing order. Never create repeated orders for the same participant.

The shared testing workspace has short provider-request budgets to prevent accidental API spend. If a provider action returns HTTP 429, follow its retry time rather than making a duplicate payment request.

Evidence and limitations

4 · Inspect the implementation

On November 2–3, 2026, the hosted integration workspace returned a real Gemini response and recorded one $11.00 USD PayPal sandbox capture, with HTTP 200 capture and webhook requests.

This is a hackathon MVP. Public demonstration data is fictional; the protected workspace uses shared test records and Render Free's ephemeral SQLite. Data may reset after deployment. No production payments, real identity verification, escrow, or payout splitting are claimed.
