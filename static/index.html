EVENT PLANNING CONTINUITY

Protect your plans between demo restarts.

Download a planning-only JSON backup, then restore it as brand-new unpaid events when necessary.

Important: Render Free stores this demo's SQLite records temporarily. A restart may erase them. CircleSplit does not keep your downloaded backup on another server. Store the file yourself in a private, secure location.

1. Export a planning backup

Private JSON

Download all supported fictional events, expenses and categories, participant names and weights, task titles, and budget targets.

Excluded: PayPal orders and captures, simulated payments, share approvals, RSVP responses, private invitations, access tokens and event history. Existing planning tasks are backed up by title, not completion state.

Maximum 25 events per file, subject to record and file-size safety limits. This file contains participant names; don't publish it or send it to judges.

2. Review and restore

Fresh unpaid copies

Select a file to preview it. Nothing will be uploaded or created until you explicitly confirm restore.

No backup selected.

No financial replay: Restore creates new event IDs and recalculates shares. Every approval, payment, RSVP and invitation starts empty. Preparation tasks return as unchecked.

What happens to the original events?

Nothing. Import never overwrites or edits an existing event. Importing the same planning contents again into the same active database is blocked to prevent accidental duplicates. A backup does not provide a recoverable PayPal ledger—payment issues still require the separate PayPal sandbox account and recovery workflow.
