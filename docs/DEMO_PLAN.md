## Recording checklist

- Use a clean 1920×1080 browser window.
- Record only a *sandbox* PayPal buyer account. Hide email, IDs and credentials.
- Keep the final video **under 3 minutes** (prefer 2:35–2:45).
- Explain what AI *actually* does and how PayPal confirms capture.
- Use narration or captions, not an unsupported claim or simulated “successful PayPal” screenshot.
- Upload the public video to YouTube with no unlicensed music.
- Link the GitHub repository and hosted demo in Devpost.
- Include judge login credentials privately in Devpost testing instructions if hosted demo is password protected.

## Go/no-go

Do **not** record a claimed real checkout before one completed sandbox capture has been verified against PayPal. If credentials or hosting are blocked, show the real non-payment flow and explain the limitations; do not pretend a simulated payment is live.
